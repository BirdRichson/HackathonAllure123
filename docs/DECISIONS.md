## 2026-10-05 — Данные и модель завода

Других данных, кроме тестовых данных организаторов, не будет. Вопросы организаторам не задаём. Все пробелы закрыты решениями D1–D11; обоснования — в [TEST_DATA.md](TEST_DATA.md), раздел 3.

| № | Решение |
|---|---|
| D1 | Одна строка таблицы линий = одна смена 8 ч; план 120 машин на линию за смену; 2 смены в сутки → 240 машин |
| D2 | Плановый такт — 4 мин; паспортный идеальный цикл для OEE — 3,8 мин |
| D3 | Плановое время = 8 ч смены; любые остановки, включая плановое ТО, уменьшают доступность |
| D4 | Состав оборудования: ABB-01…04, Камера-01/02 + печь сушки, Конвейер-01…03 (в данных есть ABB-01, ABB-04, Камера-02, Конвейер-03) |
| D5 | Критическое оборудование — всё, что останавливает линию (роботы, камеры, печь, конвейеры) |
| D6 | Модели идут смешанным потоком в пропорции месячного плана; разрыв плана 4800 с целью 5500 показывается как риск |
| D7 | Контроль качества и склады — демо-параметры |
| D8 | ML учится на синтетике, откалиброванной по тестовым данным |
| D9 | Простои — за обе смены, работа линий — за одну смену; расхождения показываются как «незафиксированные потери» |
| D10 | 22 рабочих дня в месяце (пн–пт); субботы — опция в «что если» |
| D11 | «Замена фильтра» — внеплановая остановка (`consumables`) |

**Демо-допущения в конфиге** (не влияют на расчёт KPI по тестовым данным):

| № | Допущение |

| A1 | Смены 08:00–16:00 и 16:00–00:00 |

## 2026-10-05 — Техника

- Стек:
  - симулятор — Python + SimPy;
  - бэкенд — FastAPI;
  - ML — scikit-learn и LightGBM;
  - фронтенд — React 18, Vite 6, TypeScript strict, Tailwind 4, ECharts 6, Zustand.
- ECharts 6, а не 5: в 5.x есть уязвимость XSS (GHSA-fgmj-fm8m-jvvx). `echarts-for-react` 3.0.6 поддерживает 6.x.
- Шрифты IBM Plex Sans и Plex Mono подключены из npm (`@fontsource`), без Google Fonts. Демо должно работать без интернета.
- `make demo`: бэкенд сам отдаёт собранный интерфейс из `frontend/dist`. На ноутбуке выступающего нужен один процесс и один порт (:8000).
- В коде и API идентификаторы оборудования ASCII (`CAM-02`), в интерфейсе — названия из данных («Камера-02»).
- Время везде в UTC+5 (Костанай). Часы в интерфейсе не зависят от часового пояса ноутбука.
