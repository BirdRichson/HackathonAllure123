# Сценарий защиты: 3 минуты, из них демо — 90 секунд

Регламент (п. 5.6): до 3 минут на презентацию и демонстрацию, до 3 минут на вопросы.

**Говорящих двое:**
- **Ведущий** говорит;
- **Оператор** управляет ноутбуком с двойником.

Если говорящий один, он же нажимает кнопки. Тайминги рассчитаны на это.

Все цифры ниже совпадают с интерфейсом: день завода 05.10.2026, 10:30, seed 42.

## Подготовка (за 10 минут до выхода)

1. **Запустить двойник** на ноутбуке выступающего:
   - Linux или macOS: `make demo`;
   - Windows: двойной щелчок по `scripts\demo.cmd`.

   Открыть http://localhost:8000 в Chrome, нажать F11 (полный экран), масштаб 100%.
2. **Ключ LLM в `.env`.** Двойник хотя бы раз должен был запуститься с интернетом — тогда выводы LLM лежат в кэше. Без интернета на месте всё равно работает.
3. **Сбросить демо.** Клавиша **D** → «Сбросить демо к 10:30». Скорость **×10**. Закрыть пульт (D).
4. **Вкладка «Завод»,** панели цехов закрыты.
5. **Подстраховка.** Резервное видео `docs/video/demo-backup.mp4` открыто во втором окне; PDF-презентация — на флешке.

## Если что-то пошло не так

| Ситуация | Что делать |
|---|---|
| Маркер ИИ не появился к 1:10 | Говорить по тексту и показать «Риск отказа в ближайшие 2 часа» на вкладке «Прогноз»: у Конвейера-03 риск растёт. |
| Двойник завис или не открылся | Переключиться на вкладку с резервным видео и говорить тот же текст. |
| Нет интернета | Ничего не делать: всё работает офлайн; выводы — из кэша или по шаблону. |
| Нужно начать заново | **D** → «Сбросить демо к 10:30» (меньше секунды). |

## Вопросы жюри — короткие ответы

Подробно — `docs/EXPLAIN.md`.

| Вопрос | Ответ |
|---|---|
| Это реальные данные? | Модель завода построена на ваших тестовых данных: линии, оборудование, брак, цели. История для ИИ — симуляция, откалиброванная по ним. На пилоте подключаем реальные журналы и сигналы. |
| Насколько точен прогноз? | На отдельной истории — 11 из 11 обрывов цепи, в среднем за 87 минут, без ложных тревог. Это синтетика; точность на заводе подтверждается на пилоте. |
| Почему не прогнозируете роботов? | Сбой датчика ABB внезапный, предвестника нет — модель это показывает (0,52, то есть угадывание). Там помогает скорость реакции: запас датчиков у линии. |
| LLM может выдумать цифры? | Цифры считает код. LLM пишет только текст, и каждое число в нём сверяется с расчётом. Без LLM всё работает, текст по шаблону. |
| Данные уходят в интернет? | В прототипе — только агрегаты и тексты отчётов в бесплатные API. На заводе — локальная модель, данные не покидают сеть. |
| Сколько стоит внедрение? | Пилот — около 1,5 млн ₸ (планшеты, датчики на приводы) плюс работа команды. Окупается в первый месяц даже в консервативном сценарии. |
| Как подключить реальные станки? | OPC UA или MQTT со SCADA/ПЛК; формат событий и телеметрии описан в `docs/CONTRACTS.md`. Симулятор заменяется потоком данных, остальная система не меняется. |
| Вы писали код с ИИ — понимаете его? | Да, ИИ-инструмент указан в техописании (п. 6.4). Каждая часть объяснена в `docs/EXPLAIN.md`. Можем показать любую формулу: например, OEE = доступность × производительность × качество, цикл 3,8 мин. |

## Видео для подачи (2–3 минуты)

Записывает команда по тому же сценарию, с голосом.
- **Чем записывать:** Xbox Game Bar (**Win + Alt + R**) или OBS Studio; экран 1920×1080.
- **Порядок:**
  1. 15 с — слайды «Проблема» и «Решение».
  2. Демо по таблице выше, без спешки: можно до 2 минут.
  3. 20 с — слайд «Эффект и пилот».
- **Если нужен запас:** в `docs/video/demo-backup.mp4` лежит автоматическая запись демо без голоса, с подписями (2 мин). Её можно приложить как есть или озвучить поверх.
